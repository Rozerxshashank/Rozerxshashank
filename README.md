## 🔨 Featured Projects I've worked on

###  SmartNotes - Local RAG Knowledge Base

A privacy-focused, offline-first **Retrieval-Augmented Generation system** for searching and asking questions about personal documents.

- Built document ingestion, chunking, embedding, retrieval, and generation pipelines.
- Uses vector search for semantic document retrieval.
- Designed to run locally without sending private documents to external services.
- Explored local LLM inference and fallback model architectures.

###  KhojEngine - Distributed Ingestion & Search System

A distributed document ingestion and processing pipeline designed around event-driven architecture.

- Built a Kafka-based topic architecture for document processing.
- Designed services for ingestion, transformation, and indexing.
- Implemented internal APIs for batch ingestion workflows.
- Focused on scalable and modular document processing.

### Rein - Cross-Platform Remote Desktop

Contributed to **Rein**, an open-source Electron-based remote desktop application that allows phones to control computers.

- Built a **proof of concept** that was used in the project and is actively used by the application.
- Worked on the Electron desktop application and cross-platform compatibility.
- Developed native desktop integration modules using C++ FFI.
- Worked on secure mouse and keyboard event injection.
